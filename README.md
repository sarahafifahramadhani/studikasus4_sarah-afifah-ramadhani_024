#PENJELASAN SINGKAT

Program ini berisi data produk di toko yang disimpan dalam dictionary {}, yang dimana setiap informasinya disimpan dalam key dan value. Dalam program ini user dapat melakukan 4 hal, yaitu:

1. Melihat data berisi nama barang, harga, stok dan kategori produk

2. Menambahkan kategori produk

3. Mengubah harga produk

4. Menghentikan program dengan menggunakan "break"

dalam program ini saya menggunakan:

1. while True disini agar program terus berproses dan selalu kembali ke menu utama setiap user melakukan suatu aksi.

2. if Digunakan untuk mengecek suatu kondisi. Jika suatu kondisi tersebut 'True' maka perintah di dalamnya dijalankan namun jika kondisi tersebut 'false' maka ia masuk ke perintah else.

3. elif Digunakan untuk menentukan kondisi jika kondisi if tidak terpenuhi.

4. [].pop digunakan untuk menghapus kategori produk
